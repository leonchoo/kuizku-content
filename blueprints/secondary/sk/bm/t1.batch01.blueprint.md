## Source Tag Legend

Each item below is tagged with one or more of:

- **`CURRICULUM_DERIVED`** — Sourced from Malaysia KSSM Bahasa Melayu Tingkatan 1 curriculum document / public syllabus spec. Anchored in published national curriculum, but not in the local Reference DB.
- **`REFERENCE_DB_ANCHOR`** — Sourced from a specific file in `references\`. Used only for style / question-pattern / difficulty calibration, NOT for T1 syllabus content (because no T1 file exists).
- **`INFERRED`** — Derived by extrapolation (e.g., from T2/T3 progression patterns, or from KSSR primary T5/T6 baseline). Marked as **syllabus-uncertain** — must be cross-checked against authoritative KSSM T1 syllabus before publication.

**Strict rule**: a topic tagged only `INFERRED` must NOT be claimed as "from KSSM T1" in the published 题目 metadata. Use `syllabus_source: "INFERRED_FROM_PRIMARY_T5_OR_T2_PROGRESSION"` in the JSON, not `"KSSM_T1"`.

**Before publication**, the teacher-user should review each item against the official KSSM T1 syllabus and the KPM T1 BM textbook.
