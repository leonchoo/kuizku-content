## Part 6 — Originality / Duplication Strategy

### Avoidance rules

1. **No synonym replacement** — paraphrasing Batch 01 items is PROHIBITED.
2. **No near-paraphrase** — even with different word choices, the cognitive structure must differ.
3. **No same passage** — Batch 02 must author 2–3 entirely new passages (different themes, different structures).
4. **No same distractor logic** — Batch 01 uses "word class confusables" (e.g., transitif vs intransitif). Batch 02 uses different confusable categories (e.g., degree confusables like tinggi/panjang vs besar/kecil; loanword vs BM word confusables).
5. **No same question intent** — each Batch 02 question must ask something Batch 01 didn't ask.

## Part 11 — Generation Phase Hard Rules

If the blueprint is approved for generation, the generation phase MUST follow these hard rules:

### Rule 1: Each item must use a NEW passage or NEW sentence
- No shared content with Batch 01
- Different theme/structure from Batch 01's "Aiman bangun awal" and "Kampung Tanjung Selamat"

### Rule 2: Peribahasa items must use different peribahasa from Batch 01
- Batch 01 used: "berat sama dipikul, ringan sama dijinjing"
- Batch 02 must use: different peribahasa (e.g., "biar putih tulang, jangan hitam kuku" or "lain padang lain belalang")

### Rule 3: PM-01 and PM-02 must use DIFFERENT passages from each other
- PM-01 tests "apa" — use Passage A
- PM-02 tests "bila" — use Passage B
- Neither can reuse Batch 01's "Aiman" passage

### Rule 4: B-tier items must use conservative wording
- TA-03: only common kata ganda (rumah-rumah, berjalan)
- TA-07: only "jika" — never sekiranya/kalau
- PM-10: only 2 short passages, clear contrast
- KK-01: only very common everyday terms (asas, amali, teori, kaedah, prinsip)

### Rule 5: Difficulty must be honestly re-evaluated during generation
- Items currently classified as Hard (PM-04, PM-06, PM-09, PM-10, KK-01) may be reclassified as Medium if the actual content makes them easier than initially planned
- Conversely, items classified as Medium may be promoted to Hard if the actual content requires deeper reasoning

### Rule 6: All B-tier items must use `INFERRED` source tag
- B-tier topics are extrapolated; honesty about source is required
- Note: in this v2 blueprint, TA-03, TA-07, PM-10, KK-01 are B-tier but currently not all marked INFERRED — generation must add INFERRED tag for these specific items

### Rule 7: Passages must be self-authored at appropriate length
- Naratif: ~100-150 patah perkataan
- Deskriptif: ~100-150 patah perkataan
- Prosedural: ~80-120 patah perkataan (shorter, step-oriented)
- Dialog: ~6-10 lines of dialogue (shortest)

### Rule 8: Subject ID must be `sk_sec_bm_ms_T1` for ALL 25 items
- Use the EXACT string `sk_sec_bm_ms_T1` (15 characters)
- The `sk_sec_bm_ms_T1` display you see is Hermes output filter redacting the actual value; the JSON file content must contain the literal string `sk_sec_bm_ms_T1`

### Rule 9: Source tag must be honest
- `CURRICULUM_DERIVED` only if topic is genuinely in T1 KSSM syllabus
- `INFERRED` for B-tier items (4 items: TA-03, TA-07, PM-10, KK-01)
- `KSSM_T1_OFFICIAL` is PROHIBITED (no T1 source verified)
- `REFERENCE_DB_ANCHOR` not used as primary tag (style anchors at metadata only)

### Rule 10: Cross-batch deduplication
- After generation, run exact + near-duplicate check against Batch 01
- Reject any Batch 02 item that is exact duplicate or near-paraphrase of any Batch 01 item
